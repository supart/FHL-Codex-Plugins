# v0.2.2 更新说明

v0.2.2 修复 FHL Images API 多参考图编辑的 multipart 字段组合，并整理公开审核材料。

## 修复

- 根因不是上游只收到一张图，而是默认上传格式混用了两种字段：

  ```text
  image   = 图1
  image[] = 图2
  ```

  FHL 没有把两种字段稳定合并为同一个参考图数组，导致图2的人物身份参考失效。
- 生产路径现已统一为重复的 `image` 字段：

  ```text
  image = 图1
  image = 图2
  ```

- 修复人物身份、面相、眼镜、发型和橙色上衣等特征在多图合成中丢失的问题。
- 诊断模式仍保留 `mixed`、`repeat-image`、`array` 三种字段实验，不影响生产默认值。

## 保留能力

- FHL Images API 默认路线，默认 2K，明确要求时支持已验证的 4K 比例。
- 最多 10 个独立 worker，以及批量生成、批量编辑、连续生成和 workflow 续跑补洞。
- 纯绿幕生成、本地边缘连通抠绿和真实 RGBA PNG 输出。
- 单图和多参考图编辑、建筑外观迁移与局部修复。

## 验证摘要

- 双参考图字段对照确认两张原图均完整上传，`repeat-image` 能正确保留图2的人物身份参考。
- 修复后的真实 FHL 请求中，人物位于图1左下角并手持五星红旗；面相、眼镜、发型和橙色上衣保持，光影、透视和环境融合正常。
- `--self-test-images-edit` 与真实 FHL Images API 请求均通过。
- 10 张参考图批处理均完成独立任务落盘，验证批量调度和结果保存。
- 建筑立面迁移输出为 16:9，并完成地下车库坡道旁墙面的局部二次修复。
- 绿幕处理器已验证输出真实带 Alpha 通道的 PNG。

## 稳定范围

- 普通多参考图生产建议为 1 至 5 张，并采用顺序或低并发。
- 6 至 10 张参考图保留为重任务或实验范围，不承诺上游稳定性。
- 10 worker 高并发已验证适合多个独立单参考图任务，不建议用于单个多参考图合成请求。
- FHL 上游仍可能返回 429、502、503、504 或 524；插件会重试和降速，但不能消除上游超时。

本审核包不包含 API Key、本机配置、运行日志、原始测试大图或内部路径记录。
