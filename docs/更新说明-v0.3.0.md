# v0.3.0 更新说明

v0.3.0 新增绿幕生成与透明 PNG 工作流：FHL Images API 生成纯绿幕源图后，由本地 Pillow + NumPy 处理器移除边缘连通绿幕并输出真实 RGBA PNG。

新增命令：

- `--doctor`
- `--remove-green`
- `--green-screen`
- `--split-green-grid`
- `--green-screen-batch`

处理器会保留原始绿幕图，输出透明结果、预览、manifest、质量报告、失败重试记录和 SHA-256。网格任务额外输出 1:1 母版、512×512 上传版、contact sheet 和 ZIP。

当前透明能力来自本地处理，不代表 FHL Images API 原生返回 Alpha。缺少 Codex Python、Pillow 或 NumPy 时，`--doctor` 会报告问题，普通生图功能不受影响。
