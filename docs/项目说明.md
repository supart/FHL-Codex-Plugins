# 项目说明

## 项目定位

这是给 Codex 使用的 FHL Image Gen marketplace 仓库，当前插件为 `fhl-image-gen@fhl-plugins`。v0.2.2 默认使用 FHL Images API，支持文生图、单图及多参考图编辑、批量任务、最多 10 个独立 worker、工作流续跑，以及本地绿幕转真实透明 PNG。

完整安装与命令见仓库根目录 [README](../README.md)，本次变更见 [v0.2.2 更新说明](更新说明-v0.2.2.md)。

## v0.2.2 请求规则

- 文生图和图生图走 FHL Images API。
- 多参考图按命令行顺序上传，并统一使用重复的 `image` multipart 字段。
- 单次多参考图请求由一个 worker 执行；多个独立任务才会并行分配 worker。
- 普通生产建议使用 1 至 5 张参考图并保持顺序或低并发；6 至 10 张属于重任务范围。
- 透明 PNG 由本地绿幕处理器生成，不宣称上游原生返回可靠 Alpha。

## 审核包边界

审核包只保留 marketplace 配置、插件源码、技能、图标、测试和公开文字文档。以下内容不进入审核包：

- `.git` 和 `PROJECT_CONTEXT.md`
- 本机 API 配置、密钥、worker 私有配置和插件缓存
- 运行日志、manifest、失败记录、临时输出和原始测试大图
- 测试拼图及其他演示图片
- 含本机绝对路径的内部实验文档

审核包结构为：

```text
v0.2.2/发布审核包/
├─ FHL-Codex-Plugins-v0.2.2-review/
└─ FHL-Codex-Plugins-v0.2.2-review.zip
```

本目录仅供审核；未经确认不提交、不推送、不发布。
